# €xpense

Web app per tenere traccia delle spese da carta, divise in categorie scelte da te.
Importa estratti conto in PDF, Excel (.xlsx/.xls) e CSV. Nessun server: i dati restano nel browser del dispositivo.

## Pubblicazione su Cloudflare Pages
- Framework preset: None
- Build command: (vuoto)
- Build output directory: /
- Root directory: (vuoto)

Tutti i file sono nella radice del repository (nessuna sottocartella): `index.html`, `manifest.webmanifest`, `sw.js`, `_headers` e le icone PNG.

## Dati
Salvati in locale (localStorage). Usa "Scarica backup" nella scheda Categorie per conservarne una copia.
